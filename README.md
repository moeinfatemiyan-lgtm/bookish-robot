# Admin Niayesh

A Persian, RTL, responsive landing page for Instagram management and content services.

## Stack
- Next.js App Router
- React + TypeScript
- Responsive custom CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Sections
- Hero and primary call to action
- Services
- Portfolio concept previews (replace with real work before launch)
- About
- Collaboration steps
- Instagram contact

## Notes
- Mobile navigation is state-controlled and closes after selecting a section.
- Update the Instagram URL in `app/page.tsx` if the account handle changes.
- Deploy to Vercel or another Node.js hosting provider; GitHub Pages does not directly host a standard Next.js server build.
